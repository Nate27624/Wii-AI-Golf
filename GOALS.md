# Project goals

**Initial goal document, staged for operator pinning.** This records the existing project objective and operator-approved architecture; it does not authorize production activation or new private/live operations. Goal changes require explicit operator authorization and an immutable goal revision. The manager cannot change goals by itself.

## G-ORCHESTRATION — immediate priority

Implement the V3 GitHub Work Queue and LocalOps as the unified human console. Recover work from durable task context without relying on chat history; use exclusive fenced ownership, a permanent manager, task history and curated cross-task knowledge. Demonstrate authenticated read-only operator acceptance first, then reviewed activation and rollback without dual authority.

Source: [approved architecture amendment](https://github.com/Nate27624/Wii-AI-Golf/issues/485#issuecomment-7143914532); [migration-first roster decision](https://github.com/Nate27624/Wii-AI-Golf/pull/320#issuecomment-7147241239).

## G-RESEARCH — existing long-term objective, paused for migration

Build a reproducible Wii Sports Golf research pipeline from Dolphin control through verified shot identity, provenance-gated observations and outcomes to eligible training evidence. Near-term research tracks include native accepted power, selected-ball launch state and terrain first-contact prediction. No native parity or training eligibility is implied by offline tests.

Sources: [project README at integrated V3 baseline](https://github.com/Nate27624/Wii-AI-Golf/blob/838c36990b562030a15a4d40cf7e3e2902329ccd/README.md), [#418](https://github.com/Nate27624/Wii-AI-Golf/issues/418), [#415](https://github.com/Nate27624/Wii-AI-Golf/issues/415).

## Constraints

Preserve privacy, source provenance, evidence gates and [the sole merge policy](merging.md). No unauthorized local commands, live input, private captures, training or automatic execution. Keep existing research evidence and reservations through migration; never infer release, approval or verified physical meaning. Production activation requires explicit operator authorization and a rollback rehearsal.
