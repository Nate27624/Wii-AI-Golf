## Precommitted evaluation and decision

Verify no overlap of selected `first_level_child_parent_offsets` with previous batch (the two boots may have distinct pointer-shaped inventory; if overlap or source arrangement differs, label descriptive only).
2. **Timing:** Record max non-atomic frame span. If >20, stop; if 13–20, treat as coarse timing; <=12 permits more precise relative comparisons but remains non-atomic.
3. **Negative controls:** For each relative word, compare within-idle, within-aim and between-stage changes. The current S002 summary aggregates both idle stages; if the new report lacks per-stage counts, do not claim aim-specific response. Use a source-reviewed phase-specific analyzer before claiming discriminative memory.
4. **Exclusions:** Clock-like/fixed-frame stepping or change on every transition remains non-power. One snapshot per event is not an independent trial; one run is descriptive, not held-out validation. No unverified float -> ball physics claim.
