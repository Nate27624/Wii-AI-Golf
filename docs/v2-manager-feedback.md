# S000 feedback procedure

After each substantive HANDOFF, the manager should post a short, evidence-based review to the agent's canonical PR. State one concrete success, one improvement or current blocker, and one measurable next step. Assess progress as ON TRACK, NEEDS CORRECTION, or BLOCKED. Cite actual code, tests, and preserved evidence; never invent results. A failure to merge due to failing tests is responsible behavior. Avoid personal judgments. These feedback comments are coaching, not an additional approval gate; `merging.md` remains authoritative.
