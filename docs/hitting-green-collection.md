# Guided Hitting the Green capture and automatic GitHub upload

**Status: human-controlled gameplay; read-only emulator state collection.**
**No game input, save-state load, memory write or automatic scoring is performed.**
This script produces reviewable evidence for S002 but does not prove calibrated game units.

## Run from the canonical code repository

Worker 1's workflow uses ONLY `D:\Projects\Wii Golf AI\Wii-AI-Golf` for scripts and the local savestate/scenario catalogs. The sibling `Wii-AI-Golf-Data` folder is for private capture evidence, not a second code checkout.

First ensure the collector branch is present or merged into the canonical code checkout; with the changes present, while Dolphin is unpaused and one Felk RPC bridge is running:

~~~powershell
cd "D:\Projects\Wii Golf AI\Wii-AI-Golf"
py -m unittest discover -s tests -v
py scripts/collect_hitting_green.py --shots 10
~~~

For a quick, nonuploading one-shot check:

~~~powershell
py scripts/collect_hitting_green.py --start-shot 1 --shots 1 --no-upload
~~~

**Interaction for each shot:**
1. Console: "Hitting the Green — SHOT N". Manually navigate to that numbered shot, or the indicated checkpoint if using an observed scenario plan.
2. Press Enter while the *pre-swing* screen is visible. The script reads and records a version-gated pin/start/cup snapshot and current controller state. It will refuse games other than RSPE01 disc revision 1 and modes other than training Hitting the Green (raw mode 4).
3. Console: "SWING NOW". Manually swing normally, then wait for a settled ball/result display. Press Enter to capture the *post-swing* snapshot.
4. Type whether the ball was visibly struck (y/n/?), whether the green was hit, the displayed numeric result (optional) and the exact visible unit; no conversion or assumed units.
5. The script writes a local checkpoint after every attempt. Repeat for up to ten shots. At the end (or after typing q at the *next before-shot* prompt), it automatically uploads a compact structured report to GitHub.

**Do not advance to the next shot before capturing the post-swing result.** The script does not automatically navigate or advance the game.

The script displays planned `scenario`, `checkpoint`, `shot_index` and `variant`. A plan is metadata about observed states, not synthetic new shots. Recording `shot_index` is a human-validated label until checked against the game state; the game's `current_hole_raw` may not equal 1–10 shot number.

## Upload mechanism and privacy

By default, the script:
- Creates a per-run report in the **local, ignored** sibling `Wii-AI-Golf-Data\captures`.
- Uses existing `git` authentication, temporarily checks out `origin/main` in a separate temporary Git worktree, adds ONLY one JSON report at `research/results/hitting-green/RUNID.json`, commits and pushes to an isolated `data/hitting-green-RUNID` branch. This never changes the current code checkout or pushes to `main`.
- Prints a permanent GitHub link to the uploaded JSON; share that link in the chat. If the GitHub CLI (`gh`) is installed and authenticated, it ALSO posts a link-only comment to evaluation Issue #3 for other agents.
- Does **not** upload raw memory bytes, external screenshots, savestates, disc images, trace files, file paths or private OS info. **The compact numerical observations and annotations themselves will be publicly visible if your repository is public.** Pass `--no-upload` to retain data locally only.
- If `git push` fails, preserves the local report and prints an error. It does not claim upload success.

Make sure `git remote get-url origin` refers to `Nate27624/Wii-AI-Golf`, and `git` push authentication/identity are configured. Never paste Git credentials into this chat. No additional GitHub personal-access token or remote URL change is needed.

## Scientific boundaries

The snapshot timestamps/frame windows and scene translations are live read-only data. The raw result is entered by a person; its unit is not automatically verified. A human may press Enter too early or on a different shot; multiple controlled repeats and scored attempt double annotation remain necessary. Golf scene translations are game-coordinate hypotheses, **not known meters**. No controller trace was generated by this collector and no automatic golf swing was performed.
