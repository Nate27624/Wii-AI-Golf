# Merging requirements — compatibility pointer

The canonical project merge policy is [`merging.md`](../merging.md) at the repository root. Agents S000–S005 may self-merge once **every objective checklist item** there passes. Routine external agent approval is **not** required, though GitHub branch protection and required checks still apply.

Do not use obsolete instructions from historical copies of this document to add extra reviewer bottlenecks. When blocked by failing tests, conflicting ownership, security/privacy concerns or permission rules, resolve the objective blocker or escalate to the operator. Never bypass protections.
